title: "Enrollment code to active FDE"
description: "Redeem an enrollment code, receive company identity, and prove your first KHAW-ready account state."
---

You may start with only an enrollment code. That code is enough to begin, but it is not enough to mutate systems. The goal of enrollment is to create a traceable identity and route you to the right access requests.

## What enrollment should give you

- A company identity record tied to your real person.
- A company email or the ticket proving email is being provisioned.
- A KHAW profile/workstation record.
- The first support channel and owner for blocked access.
- A list of credentials that still need human/operator approval.

<Callout type="info">
  KHAW can produce the onboarding plan before email exists. Treat that plan as the source of truth for what access is pending, not as proof that access has already been granted.
</Callout>

## Redeem and verify

```bash
# The exact redeem command may be provided in your hiring note.
# Keep the code private; never paste it into a public issue or screenshot.
khaw fde enroll --code <enrollment-code> --dry-run
khaw fde provision --code <enrollment-code> --dry-run --json
khaw fde verify --json
```

Expected result shape:

```json
{
  "fde": "your-name",
  "email": { "status": "pending-or-active" },
  "workspace": { "status": "planned-or-ready" },
  "next_actions": ["request Google Workspace", "register SSH key"]
}
```

## If you do not have email yet

Ask for exactly this, and include your enrollment proof without the raw code:

```text
I have redeemed my KHAL FDE enrollment code. Please provision or confirm:
1. company email account;
2. Gitea account/group membership;
3. KHAW profile/workstation binding;
4. SSH/LXC access route;
5. OpenRouter or approved model-provider credential route.
```

## Evidence to keep

- Command used, with enrollment code redacted.
- `khaw fde verify --json` output.
- The access owner/channel returned by the onboarding plan.
- Any ticket ID or approval message for email, SSH, Gitea, or model credentials.
