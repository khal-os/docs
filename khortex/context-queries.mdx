Khortex/Brain are useful when you ask for sourced current truth, not generic advice.

## Basic query

```text
Find current context for <repo/project/customer/work>. Return only sourced facts, source handles, open risks, and the next safe command. If the source is stale or missing, say so.
```

## Release query

```text
Before release, fetch current branch/ref, PR/CI/deploy evidence, target environment, rollback path, and customer/prod boundary. Return GO/NO-GO with proof handles.
```

## FDE onboarding query

```text
For identity <identity>, inspect the onboarding receipt and KHAW/FDE docs. Tell me which of email, Gitea, LXC, KHAW, KHAL, SSH, and model access is proven, pending, or blocked.
```

## Answer quality checklist

A good answer includes source handles, timestamps when relevant, current commands, and limitations. A bad answer relies on memory or invents missing URLs/secrets.
