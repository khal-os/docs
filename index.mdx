This is the first page for a newly hired Forward Deployed Engineer. Assume you have **only an enrollment code** and no company email yet. Your job is not to memorize the platform; your job is to get an account, get a workstation, install the KHAL/KHAW tools, pair with your agent, and produce a small proof safely.

## What you should know before your first ticket

- **Khal OS** is where packs run: a browser-based OS shell with apps, settings, terminal, services, and customer environments.
- **KHAW** is the FDE/agent workstation and governance harness: it installs tools, manages purpose/wish work, and gives your agent the right context.
- **Khortex/Brain** are context and reasoning surfaces: use them to ask, retrieve, and preserve evidence instead of relying on memory.
- **KHAL CLI (`khal`)** is the app/deploy companion. Install it from `https://install.khal.ai/app-kit`, not npm.
- **Private engineering repos** live in KHAL Gitea. Public docs live on GitHub + Mintlify.

## First proof target

A new FDE's first proof is intentionally small:

```bash
khal --version
khaw --version
khal auth status --target dev --json
khal new app hello-fde
cd hello-fde
bun install
bun run build
bun run typecheck
khal install . --target dev --dry-run --json
```

If any step fails, keep the output and paste it into your KHAW agent with the prompt below.
